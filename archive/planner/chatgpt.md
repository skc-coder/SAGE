## My common traps

### Productive procrastination

Examples:

- App ideas.
    
- Startup ideas.
    
- Linux customization.
    
- Researching careers endlessly.
    
- Building tools instead of using them.
    

These feel productive but often delay the real work.

### Opportunity FOMO

I often worry about missing opportunities.

Reality:

- The bigger risk is losing focus.
    
- Most opportunities will still exist later.
    
- Not every opportunity deserves attention now.
    

### Planning addiction

Creating plans feels like progress.

Actual progress is:

- Lectures completed.
    
- Problems solved.
    
- Tests taken.
    
- Fitness sessions completed.

## Decision filter

When a new idea appears:

1. Does this help my current goals?
    
2. Does it need to be done now?
    
3. What important work will it delay?
    

If it fails these questions:

- Write it down.
    
- Ignore it for now.
