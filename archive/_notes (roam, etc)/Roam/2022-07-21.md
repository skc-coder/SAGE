      * ### Live Previews
        * One final tip, if you have a complex equation, seeing it visually as you type can be helpful. Block references to the rescue. Start writing your formula, then create and paste a block reference to it, using either Alt-Drag or Copy Block Ref from right-clicking the bullet. Then continue to work on your formula. The block reference will act as a live preview. You can apply this tip to other formatting methods too.

      * ## Advanced Formatting
      * There is another lesser-known command in Roam called "Hiccup" which lets you render arbitrary HTML in your notes. We can use Hiccup to address a few shortcomings with Roam, at least at the time of writing this. *(Until very recently, you could do more, but due to some security issues found, the hiccup command has been neutered a little).*
      * For example, often you want to introduce some kind of separator, hitting enter to create a few empty blocks feels inelegant. You can easily add a horizontal line using:
      * `:hiccup [:hr]`
      * I use a text expansion program to have it available as a fast keyboard shortcut. I'll cover more about this in future lessons, and we'll talk about how we can use CSS to change Roam's appearance. You can use that to make this line bolder or adjust the spacing.
