# Question 27: Homogeneity Property HCF(a/c, b/c) for HCF(a,b) = c

For any three natural numbers $a, b,$ and $c$, if $\operatorname{HCF}(a, b) = c$, then $\operatorname{HCF}\left(\frac{a}{c}, \, \frac{b}{c}\right)$ is:

(a) $a/c$  
(b) $b/c$  
(c) $c$  
(d) Always 1  

> [!faq]- View Solution
> ### Concept: Definition of Highest Common Factor
> By definition, if $\operatorname{HCF}(a, b) = c$, then $c$ is the greatest common factor of $a$ and $b$.
> 
> We can write:
> $$a = c \cdot x \implies \frac{a}{c} = x$$
> $$b = c \cdot y \implies \frac{b}{c} = y$$
> 
> where $x$ and $y$ **MUST be co-prime integers** ($\operatorname{GCD}(x, y) = 1$).  
> If $x$ and $y$ shared any common factor $d > 1$, then $c \cdot d$ would divide both $a$ and $b$, making $\operatorname{HCF}(a, b) = c \cdot d > c$, which contradicts the fact that $\operatorname{HCF}(a, b) = c$.
> 
> Therefore:
> $$\operatorname{HCF}\left(\frac{a}{c}, \frac{b}{c}\right) = \operatorname{HCF}(x, y) = \mathbf{1 \text{ (Always 1)}}$$
> 
> **Correct Answer:** **(d) Always 1**
