# CDS Practice Q29: Factorable Polynomial LCM

## Question Text

Find the LCM of the polynomials:
$$P(x) = x^3 - 2x^2 - x + 2$$
$$Q(x) = x^3 - x^2 - 4x + 4$$

**Options:**
- (a) $(x^2 - 1)(x^2 - 4)$
- (b) $(x^2 + 1)(x^2 - 4)$
- (c) $(x^2 + 1)(x^2 + 2)$
- (d) None of these

---

## Detailed Mathematical Solution

### Step 1: Factorize $P(x)$ by Grouping
Group terms to isolate common binomial factors:
$$P(x) = x^3 - 2x^2 - x + 2$$
$$P(x) = x^2(x - 2) - 1(x - 2)$$
$$P(x) = (x - 2)(x^2 - 1)$$
$$P(x) = (x - 2)(x - 1)(x + 1)$$

### Step 2: Factorize $Q(x)$ by Grouping
Group terms to isolate common binomial factors:
$$Q(x) = x^3 - x^2 - 4x + 4$$
$$Q(x) = x^2(x - 1) - 4(x - 1)$$
$$Q(x) = (x - 1)(x^2 - 4)$$
$$Q(x) = (x - 1)(x - 2)(x + 2)$$

### Step 3: Compute LCM
Collect the highest power of all present linear factors:
- Factor $(x - 1)$: power 1
- Factor $(x + 1)$: power 1
- Factor $(x - 2)$: power 1
- Factor $(x + 2)$: power 1

$$\operatorname{LCM}(P(x), Q(x)) = (x - 1)(x + 1)(x - 2)(x + 2)$$

Now combine linear pairs into quadratic terms:
$$(x - 1)(x + 1) = x^2 - 1$$
$$(x - 2)(x + 2) = x^2 - 4$$

$$\operatorname{LCM}(P(x), Q(x)) = (x^2 - 1)(x^2 - 4)$$

**Correct Answer**: **(a) $(x^2 - 1)(x^2 - 4)$**

---

## Key Takeaway & Exam Strategy
Always factorize cubic polynomials into irreducible linear factors first. Combine linear pairs $(x-a)(x+a) = x^2 - a^2$ at the very end to match the given option format easily.
