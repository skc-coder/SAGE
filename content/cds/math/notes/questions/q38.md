# CDS PYQ 2014 II Q38: Fast HCF Option Root Testing

## Question Text

What is the highest common factor (HCF) of $P(x) = 2x^3 + x^2 - x - 2$ and $Q(x) = 3x^3 - 2x^2 + x - 2$?

**Options:**
- (a) $x - 1$
- (b) $x + 1$
- (c) $2x + 1$
- (d) $2x - 1$

---

## Detailed Mathematical Solution

### Method 1: Fast Option Root-Testing Heuristic (5-Second Exam Trick)

Instead of performing long Euclidean division on cubic polynomials, test the roots of the options!

#### Test Option (a) $x - 1 \implies x = 1$:
Substitute $x = 1$ into both polynomials:
$$P(1) = 2(1)^3 + (1)^2 - (1) - 2$$
$$P(1) = 2 + 1 - 1 - 2 = 0 \quad \checkmark$$

$$Q(1) = 3(1)^3 - 2(1)^2 + (1) - 2$$
$$Q(1) = 3 - 2 + 1 - 2 = 0 \quad \checkmark$$

Since $x = 1$ makes **both $P(1) = 0$ and $Q(1) = 0$**, $(x - 1)$ is a factor of both polynomials!

**Correct Answer**: **(a) $x - 1$**

---

### Method 2: Standard Factorization by Grouping

#### Factorizing $P(x)$:
$$P(x) = 2x^3 - 2 + x^2 - x$$
$$P(x) = 2(x^3 - 1) + x(x - 1)$$
$$P(x) = 2(x - 1)(x^2 + x + 1) + x(x - 1)$$
$$P(x) = (x - 1)[2(x^2 + x + 1) + x]$$
$$P(x) = (x - 1)(2x^2 + 3x + 2)$$

#### Factorizing $Q(x)$:
$$Q(x) = 3x^3 - 3x^2 + x^2 + x - 2$$
$$Q(x) = 3x^2(x - 1) + (x - 1)(x + 2)$$
$$Q(x) = (x - 1)(3x^2 + x + 2)$$

Comparing shared factors:
$$\operatorname{HCF}(P(x), Q(x)) = x - 1$$

---

## Key Takeaway & Exam Strategy
> [!TIP]
> **5-Second Rule for HCF Options**:
> When given linear binomial options $(x - \alpha)$, test $x = \alpha$ into both polynomials. The option that gives $P(\alpha) = 0$ AND $Q(\alpha) = 0$ is the guaranteed HCF!
