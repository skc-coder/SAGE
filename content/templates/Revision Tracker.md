> [!info] Overview
> Master table across all subjects, used to decide what to revise and when. Sort by "Next Due" to find the most overdue topics. Friday's mixed-practice slot and Saturday's spaced-repetition redo slot should both pull from this table — not from a single subject.

---

## How to Use

1. After revising a topic, update **Last Revised** and set **Next Due** using the spacing intervals: Day 1 → Day 3 → Day 7 → Day 15 → Day 30.
2. Set **Confidence** (1–5) honestly after each revision — this determines how far out the next interval should be. Low confidence (1–2) resets the interval back to Day 1–3 regardless of the schedule above.
3. For Friday's mixed session: pull the 3 oldest **Next Due** entries regardless of subject.
4. For Saturday's redo slot: pull entries from the current week's subject specifically.
5. The **Links** column holds three links in one cell: topic note, subject's mistake log, subject's MOC/cheat sheet — in that order.
