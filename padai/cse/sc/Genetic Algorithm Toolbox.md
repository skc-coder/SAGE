# Genetic Algorithm Toolbox (MATLAB)

**Genetic Algorithm (GA)** is a stochastic optimization method inspired by natural selection. MATLAB's GA toolbox provides functions and apps to solve optimization problems using evolutionary algorithms.
## Key Functions
- `ga()` — single-objective GA solver
- `gamultiobj()` — multi-objective GA (NSGA-II based)
- `gaoptimset()` — configure GA options (population size, generations, mutation rate, etc.)

## Genetic Algorithm App
Interactive GUI for:
- Define objective function
- Set variable bounds and constraints
- Configure population and stopping criteria
- Visualize convergence and solutions

## Workflow
1. Define fitness function (what to minimize/maximize)
2. Set variable bounds and constraints
3. Configure GA parameters (population size, generations, selection/crossover/mutation operators)
4. Run solver
5. Analyze results (best solution, convergence history)
