**Bandwidth & Efficiency Formulae — Computer Networks (GATE)**

---

## Propagation Delay

$$T_p = \frac{\text{Distance}}{c \cdot \text{NRF}}$$

Where NRF = propagation speed factor (e.g. 2/3 of light speed in copper).

---

## Transmission Time (Sender's Time)

$$T_t = \frac{L}{B}$$

Where $L$ = frame size (bits), $B$ = bandwidth (bps).

---

## Bandwidth-Delay Product

$$\text{BDP} = B \times T_p \quad \text{(bits in flight)}$$

---

## Efficiency (Stop-and-Wait)

$$\eta = \frac{1}{1 + 2a} \quad \text{where } a = \frac{T_p}{T_t}$$

---

## Efficiency (Sliding Window)

Let $W$ = window size, $a = T_p / T_t$

$$\eta = \begin{cases} \dfrac{W}{1 + 2a} & \text{if } W < 1 + 2a \[10pt] 1 & \text{if } W \geq 1 + 2a \end{cases}$$

---

## Throughput

$$\text{Throughput} = \eta \times B$$

---

## RTT (Round Trip Time)

$$\text{RTT} = 2 \times T_p$$

---

## Cycle Time (for efficiency calculation)

$$T_{\text{cycle}} = T_t + 2T_p + T_{\text{ack}}$$

Usually $T_{\text{ack}} \approx 0$, so:

$$T_{\text{cycle}} = T_t + 2T_p$$

---

## Go-Back-N / Selective Repeat — Window Size Constraints

|Protocol|Max Window Size|
|---|---|
|Go-Back-N|$2^n - 1$|
|Selective Repeat|$2^{n-1}$|

Where $n$ = number of bits in sequence number field.

---

## CSMA/CD — Minimum Frame Size

$$L_{\min} = 2 \times T_p \times B$$

Ensures sender is still transmitting when collision signal arrives.

---

## Shannon's Channel Capacity

$$C = B \cdot \log_2(1 + \text{SNR}) \quad \text{(bps)}$$

---

## Nyquist Capacity (Noiseless Channel)

$$C = 2B \cdot \log_2 M$$

Where $M$ = number of signal levels.

---

## Error Detection — Hamming Distance

- Detect $d$ errors: $d_{\min} \geq d + 1$
- Correct $d$ errors: $d_{\min} \geq 2d + 1$

---

**Key relation to remember:**

$$a = \frac{T_p}{T_t}, \quad 1 + 2a = \frac{T_t + 2T_p}{T_t}$$


**TCP Congestion Control — Slow Start & Related Concepts**

---

## Key Variables

|Variable|Meaning|
|---|---|
|`cwnd`|Congestion Window (sender-side limit)|
|`ssthresh`|Slow Start Threshold|
|`rwnd`|Receiver Window|
|`W`|Effective window = $\min(\text{cwnd}, \text{rwnd})$|

---

## Phases

### 1. Slow Start

- `cwnd` starts at **1 MSS**
- Doubles every RTT (exponential growth)
- Continues until `cwnd` reaches `ssthresh` **or** loss occurs

$$\text{cwnd}_{n+1} = 2 \times \text{cwnd}_n$$

### 2. Congestion Avoidance

- Triggered when `cwnd >= ssthresh`
- Increases by **1 MSS per RTT** (linear growth)

$$\text{cwnd}_{n+1} = \text{cwnd}_n + 1$$

### 3. On Loss Event

|Loss detected by|Action|
|---|---|
|**Triple Duplicate ACK** (TCP Reno)|`ssthresh = cwnd/2`, `cwnd = ssthresh` → enter CA|
|**Timeout**|`ssthresh = cwnd/2`, `cwnd = 1` → restart Slow Start|

---

## Standard Problem Template

**Q: Given initial ssthresh = X, trace cwnd for each RTT until transmission of N-th segment.**

**Step-by-step approach:**

```
RTT 1 : cwnd = 1   → SS
RTT 2 : cwnd = 2   → SS
RTT 3 : cwnd = 4   → SS
...
RTT k : cwnd = ssthresh → switch to CA
RTT k+1 : cwnd = ssthresh + 1  → CA
...
```

---

## Example (Standard GATE Type)

**Given:** ssthresh = 8, loss (timeout) at cwnd = 12

```
RTT 1  → cwnd = 1   (SS)
RTT 2  → cwnd = 2   (SS)
RTT 3  → cwnd = 4   (SS)
RTT 4  → cwnd = 8   (SS→CA, cwnd hit ssthresh)
RTT 5  → cwnd = 9   (CA)
RTT 6  → cwnd = 10  (CA)
RTT 7  → cwnd = 11  (CA)
RTT 8  → cwnd = 12  → TIMEOUT here
         ssthresh = 12/2 = 6
         cwnd = 1   → restart SS
RTT 9  → cwnd = 1   (SS)
RTT 10 → cwnd = 2   (SS)
...
RTT 14 → cwnd = 6   (hit new ssthresh → CA)
RTT 15 → cwnd = 7   (CA)
```

---

## Common GATE Questions & How to Handle

### Type 1 — "What is cwnd after RTT n?"

- Trace RTT by RTT from scratch
- Watch for ssthresh crossings and loss events

### Type 2 — "When does cwnd first reach value X?"

- In SS: $\text{cwnd} = 2^{(\text{RTT}-1)}$, so RTT = $\log_2 X + 1$
- In CA: linear, count RTTs after ssthresh

### Type 3 — "How many segments sent in RTT n?"

- Segments sent in that RTT = cwnd value at that RTT

### Type 4 — "Total segments sent up to RTT n?"

$$\text{Total} = \sum_{\text{RTT}=1}^{n} \text{cwnd}_{\text{RTT}}$$

### Type 5 — "After 3 dup ACKs at cwnd = W"

```
ssthresh = W/2
cwnd     = W/2     ← NOT 1 (Reno fast recovery)
Phase    = Congestion Avoidance
```

---

## TCP Tahoe vs Reno

|Event|TCP Tahoe|TCP Reno|
|---|---|---|
|Timeout|cwnd=1, ssthresh=cwnd/2|cwnd=1, ssthresh=cwnd/2|
|3 Dup ACK|cwnd=1, ssthresh=cwnd/2|cwnd=ssthresh=cwnd/2 (fast recovery)|

---

## Quick Reference — SS to CA Transition

$$\text{RTT at which CA starts} = \log_2(\text{ssthresh}) + 1$$

(Only valid when starting from cwnd=1 with no interruptions)

---

## Things That Trip People Up

- cwnd = ssthresh → that RTT is still **Slow Start** in most textbook conventions (some say CA begins _at_ ssthresh — check which convention the question uses)
- After fast recovery (3 dup ACK), cwnd = ssthresh, **not 1**
- Segments sent = cwnd (in MSS units), not cwnd+1
- ssthresh is always floored: $\lfloor \text{cwnd}/2 \rfloor$
