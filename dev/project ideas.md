* Big Project Ideas

** Website Downloader
- Recursive website downloader (especially for course websites)
- User can specify one or more starting URLs
- Downloader fetches:
  - Pages linked on the current page
  - Resources attached to those pages (PDFs, images, videos, etc.)
- Support configurable depth levels (URL tree)
- Visualize URLs as a tree
- Tree editor to select/deselect nodes before downloading

- Guides

*** Guides

- Save content into specified folders
- Attach searchable comments/notes
- Store original web URLs alongside downloaded files

- Highlight and annotate web pages
- Uses:
  - Browser download history

- Automatically organize saved content into appropriate folders
