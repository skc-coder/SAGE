
| Type                    | Average                 | Sum                               |
| ----------------------- | ----------------------- | --------------------------------- |
| Natural ($1,2,3\ldots$) | $\frac{n+1}{2}$         | $\frac{n(n+1)}{2}$                |
| Even ($2,4,6\ldots$)    | $n+1$                   | $n(n+1)$                          |
| Odd ($1,3,5\ldots$)     | $n$                     | $n^2$                             |
| Whole ($0,1,2\ldots$)   | $\frac{n-1}{2}$         | $\frac{n(n-1)}{2}$                |
| Squares ($n^2$)         | $\frac{(n+1)(2n+1)}{6}$ | $\frac{n(n+1)(2n+1)}{6}$          |
| Cubes ($n^3$)           | $\frac{n(n+1)^2}{4}$    | $\left[\frac{n(n+1)}{2}\right]^2$ |

- Even formula directly derived from natural formula. Note that there must be n even numbers.

#### Key Relations
- Any AP: $\text{avg} = \frac{\text{first} + \text{last}}{2}$
- Range: $\text{max} - \text{min} = (n-1) \times d$ (where $d$ = common difference)
