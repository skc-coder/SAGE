1. Time Complexity of Recursive Programs

T(n) = time taken by a program with input value n

1.1 Introduction to Recurrence Relations

T(n)=T(n/2)+n(NOT T(n)=T(n/2)+n, i.e. cost of current level)

Common Mistake

These are NOT the same!

Three Methods to Solve Recurrences

  1. Iteration / Repeated Substitution
  2. Tree Method
  3. Master Theorem

1.1.1 Iteration Method (Repeated Substitution)

Example 1 — T(n)=T(n−1)+1

T(n)=T(n−1)+1 =T(n−2)+1+1=T(n−2)+2 =T(n−k)+k

If T(1)=1, set k=n−1:

T(n)=T(1)+n−1=n​⟹T(n)=Θ(n)

Example 2 — T(n)=T(n/2)+n

T(n)=T!(2n​)+n=T!(4n​)+2n​+n=T!(2kn​)+⋯+2n​+n

When 2k=n, i.e. k=log2​n:

T(n)=T(1)+n![1+21​+41​+⋯+2k−11​]=T(1)+n⋅2k−12k−1​

∴T(n)=2n−1=Θ(n)

1.1.2 Tree Method

Use tree method when iteration becomes lengthy and confusing.

Example — T(n)=T!(5n​)+T!(54n​)+n

Level   Nodes (index)              Cost
  0         n                  →    n
  1       n/5,  4n/5           →    n
  2     n/25, 4n/25, 4n/25, 16n/25 →  n
  ...
  k     (4/5)^k · n            →    n
  • Shortest path (always take n/5): stops when (1/5)k⋅n=1⇒k=log5​n
  • Longest path (always take 4n/5): stops when (4/5)k⋅n=1⇒k=log5/4​n

nlog5​n≤T(n)≤nlog5/4​n

Since log5/4​n=log2​(5/4)log2​n​=Θ(log2​n):

∴T(n)=Θ(nlogn)

Tree Method Rule Always find lower bound (shortest leaf path) and upper bound (longest leaf path), then conclude Θ(f(n)).

Example — T(n)=T!(3n​)+T!(32n​)+n2

Each level costs:

n2+95n2​+(95​)2n2+⋯

T(n)=n2(1+95​+(95​)2+⋯)=n2⋅1−5/91​=Θ(n2)

Geometric Series Formula (Essential!)

1+c+c2+⋯+cn=∑i=1n​ci={Θ(1)​if c<1 Θ(n)​if c=1 Θ(cn)​if c>1​

General Solution for T(n)=aT!(bn​)+cnk

Let m=logb​n (depth of tree):

T(n)=cnk+ac!(bn​)k+a2c!(b2n​)k+⋯+am−1c!(bm−1n​)k

T(n)=cnk!(1+bka​+b2ka2​+⋯+bk(m−1)am−1​)

Using GP formula:

T(n)=Θ!(nk⋅g(n))where g(n)={1​if a<bk logb​n​if a=bk (bka​)logb​n​if a>bk​​

1.2 Master Theorem

Theorem 4.1 (Master Theorem) Let a≥1, b>1 be constants, f(n) a function, and T(n)=aT(n/b)+f(n). Compare f(n) with nlogb​a:

CaseConditionResult
1f(n)=O(nlogb​a−ε) for some ε>0T(n)=Θ(nlogb​a)
2f(n)=Θ(nlogb​a)T(n)=Θ(nlogb​alogn)
3f(n)=Ω(nlogb​a+ε) for some ε>0, and af(n/b)≤cf(n) for c<1T(n)=Θ(f(n))

⚠️ Polynomial Greater — Critical Requirement

f(n) must be polynomially greater than nlogb​a — not just asymptotically.

Example: T(n)=2T(n/2)+nlogn

nlog2​2=n1=nIs nlogn polynomially greater than n?

nnlogn​=logn>1⇒ NOT polynomially greater. Cannot apply Master Theorem!

If instead of nlogn we had n2logn, then nn2logn​=nlogn>1 — polynomially greater ✓

Note on 2n and n!: 2n>n is a polynomial, so 2n is polynomially greater. Same for n!

Proof Sketch (Tree Method)

T(n) = f(n) + a·f(n/b) + a²·f(n/b²) + ... + a^(k-1)·f(n/b^(k-1))   [k = log_b n]
  • If f(n)>alogb​n: series is decreasing → T(n)=Θ(f(n)) ← Case 3
  • If f(n)<alogb​n: series is increasing → T(n)=Θ(alogb​n)=Θ(nlogb​a) ← Case 1
  • If f(n)=alogb​n: all terms equal → sum with GP → T(n)=Θ(f(n)⋅logb​n) ← Case 2

1.2.1 Generalized Master Theorem

Handles cases where f(n)=Θ(nlogb​a) but with logarithmic factors.

Extended Case 2 (replaces the simple Case 2):

If f(n)=Θ(nlogb​a⋅logkn) with k≥0⟹T(n)=Θ(nlogb​a⋅logk+1n)

Sub-cases for Case 2:

ConditionResult
f(n)=Θ!(lognnlogb​a​)T(n)=Θ(nlogb​aloglogn)
f(n)=Θ!(logpnnlogb​a​) with p≥2T(n)=Θ(nlogb​a)

Example — T(n)=2T(n/2)+lognn​, T(2)=1

Using substitution (since master theorem fails here):

T(n)=2kT!(2kn​)+∑i=0k−1​log(n/2i)n​[k=logn−1]

T(n)=∑i=0logn​logn−in​=n∑l=1logn​l1​=Θ(nloglogn)

Example — T(n)=2T(n/2)+(logn)2n​, T(2)=1

T(n)=∑i=1logn​i2n​=n∑i=1logn​i21​≈n⋅6π2​=Θ(n)

Extended Master Theorem (Full Form)

Applies to: T(n)=aT!(bn​)+f(n) where a≥1, b>1, f(n) is asymptotically positive.

CaseConditionResult
1f(n)=O(nlogb​a−ε)T(n)=Θ(nlogb​a)
2af(n)=Θ(nlogb​alogkn), k≥0T(n)=Θ(nlogb​alogk+1n)
2bf(n)=Θ!(lognnlogb​a​)T(n)=Θ(nlogb​aloglogn)
2cf(n)=Θ!(logpnnlogb​a​), p≥2T(n)=Θ(nlogb​a)
3f(n)=Ω(nlogb​a+ε)T(n)=Θ(f(n))

Example — T(n)=4T(n/2)+(logn)2n​

nlog2​4=n2(logn)2n​≪n2

(logn)2n​ vs n2⇒1<nlogn (polynomially greater)

f(n)=O(n2−ε)⟹T(n)=Θ(n2)

1.2.2 Problems Master Theorem Cannot Solve

Master theorem requires: a≥1 constant, b>1 constant, f(n) positive

T(n)=2T(n/logn)+n2b is not constant

T(n)=2T(n/(3/4))+nb=3/4<1

T(n)=25T(n/2)+nsinnTrigonometry not allowed

1.3 Change of Variable

Replace existing variable with a new one to simplify the recurrence.

Example 1 — T(n)=T(n​)+n​

Let n=2m, so T(2m)=T(2m/2)+2m/2. Let S(m)=T(2m):

S(m)=S(m/2)+2m/2

Hmm, still complex. Alternatively:

S(m)=Θ(2m/2⋅logm)⟹T(n)=Θ(n​⋅loglogn)

Example 2 — T(n)=T!(161n​)161⋅n

Take log on both sides:

logT(n)=161⋅logT!(161n​)+logn

Let S(n)=logT(n):

S(n)=161⋅S(n/161)+logn

By master theorem: nlog161​161=n1=n>logn⟹S(n)=Θ(n)

T(n)=Θ(en)=O(2n)​

Example 3 — T(n)=n​,T(n​)+100n

Divide by n:

nT(n)​=n​T(n​)​+100

Let S(n)=T(n)/n:

S(n)=S(n​)+100

Let n=2m: S(2m)=S(2m/2)+100. Let R(m)=S(2m):

R(m)=R(m/2)+100⟹R(m)=Θ(logm)

Back-substituting: m=logn, so R(m)=Θ(loglogn)

S(n)=Θ(loglogn)⟹T(n)=n⋅S(n)

T(n)=Θ(nloglogn)​
